# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Fixed
- **Milestone 18 (AI Thumbnail Prompt & Image Generation)**: Extended the Studio Production Suite with a provider-agnostic AI Image Generation foundation. Expanded `ThumbnailConcept` with advanced prompt metadata (Subject, Lens, Composition, Negative Prompt). Implemented an automated `studio_analyze_thumbnail_quality` background job that executes post-generation to compute a deep Readiness Score. Built a mock preview framework (`/api/studio/thumbnail-preview`) ready to be hot-swapped with actual Image Providers. Completely rewrote Production Export logic to dynamically construct structured `.md` and `.txt` files containing accurate AI prompt parameters instead of dumping raw JSON.
- **Secure API Key Management (Milestone 10)**: Implemented a highly secure, professional UI for managing OpenAI, Gemini, and OpenRouter API keys directly from the browser without server restarts. Engineered a rigorous `EncryptionService` utilizing AES-256-GCM to securely encrypt keys at rest while automatically masking them (`sk-********`) before frontend transmission. Built an `AIStorageAdapter` interface, guaranteeing future flexibility for secrets manager or database migrations. Upgraded all AI providers to dynamically pull extended configuration attributes (`temperature`, `maxTokens`, `timeout`, `retryCount`) on the fly, and created a reactive `AIProviderCard` UI component with seamless testing endpoints.
- **Backend Architecture & Job System (Milestone 9)**: Transformed the synchronous AI backend into a scalable, asynchronous Job System capable of handling heavy, multi-minute AI extraction and analysis workloads without hitting serverless execution limits. Built a local `JobRepository` and `JobManager` integrated with a new `jobs` database table. Refactored six long-running AI API endpoints (Assembly, Extraction, Intelligence Analyze/Optimize, Title/Script Analyze) to instantly return `jobId` and execute asynchronously. Designed robust advanced job features including generic retry systems with exponential backoff (up to 2 retries), execution timeout guards, job cancellation pipelines via `/api/jobs/[id]`, and error recovery tracking. Finally, built an abstraction layer via a `useJob` React hook to seamlessly render visually-polished, reactive `JobProgress` components overriding blocking loaders across the entire Dashboard.
- **AI Knowledge Base & Builder UX Redesign (Milestone 8)**: Transformed the legacy Library and Builder into a professional, scalable, configuration-driven AI Knowledge Base. Introduced a dynamic Universal Knowledge Editor supporting manual creation, editing, duplication, metadata editing, and notes. Replaced horizontal tabs with a configuration-driven left sidebar that supports unlimited folder hierarchies scoped to knowledge categories. Built a Global Search. Refactored the Builder into a Modular Assembly Engine with independent collapsible sections and a Knowledge Picker component supporting Search, Folders, and AI Previews, enabling Niche Blending logic. Rebuilt the Live Master Prompt to dynamically update as knowledge is selected. Completely modernized the Intelligence Extractor allowing users to save individual atomic modules directly into specific Library categories with full backward compatibility.
- **Viral Intelligence & Optimization Engine (Milestone 7)**: Transformed the application into a complete YouTube Viral Intelligence Platform. Implemented a reusable Intelligence Layer using Explainable AI (XAI) forcing all modules to return raw scores, confidence levels, AI Coach insights (why it matters, expected impact), evidence, and assumptions. Constructed an Intelligence Graph to map node relationships (strong, weak, conflicting). Created an independent `/intelligence` dashboard featuring an Optimization Sandbox (side-by-side A/B comparisons without replacing original text) and an Intelligence Timeline. All modules (Hook, Title, CTA, Thumbnail, Story, SEO) include robust 'Save to Library' functionality for Historical Learning.
- **AI Knowledge Assembly Engine (Milestone 6B)**: Built a new Assembly Builder workspace to construct brand-new, original YouTube scripts by combining extracted Knowledge Objects. Implemented a Rule-Based Hybrid Conflict Detection Engine, 5-Pillar Assembly Scoring (Compatibility, Retention, Emotional, Narrative, Confidence), and dynamic Live Prompt Preview. Introduced the AI Memory Profile system to customize script generations (Tone, Pacing, Complexity) and Assembly Templates to persist the entire builder configuration to the database.
- **Knowledge Extraction Engine (Milestone 6A)**: Transformed the Script Analysis feature into an atomic Knowledge Extraction Engine. Decomposed competitor scripts into 28 standardized, highly reusable knowledge modules (Hooks, Tones, CTAs, etc.). Implemented relational mapping (`targetId`, `targetType`), AI performance scoring (usefulness, reuse, uniqueness), strict schema versioning, and an enhanced duplicate detection system allowing users to Update Existing or Save as New items in the Knowledge Base.
- **Script Analysis Intelligence Dashboard**: Upgraded the Script Analysis module into a professional Intelligence Dashboard. Enforced strict 14-section TypeScript-validated JSON schemas across all AI providers. Extracted frontend rendering into 14 separate, reusable React components (`ScriptAnalysisDashboard`). Added granular "Save to Library" functionality to every individual analysis module (e.g. Hooks, Story Structure, CTAs) with automated metadata mapping.
- **Library Architecture Redesign**: Transformed the Library into a scalable knowledge base featuring a universal `LibraryItem` model, `LibraryFolder` support, and a unified `SaveToLibraryModal`. Users can now save, organize (into unlimited folders), and duplicate-check items across the entire app (Wizard, History, and Output Viewers). Redesigned `/library` page to feature dedicated 'Video Ideas' and 'My Library' workspaces.
- **Dependencies**: Successfully installed all required packages via `npm install` in the `next-app` directory. Tested server startup via `npm run dev`.
- **Dashboard White Screen**: Fixed a synchronous `TypeError: Invalid URL` crash during dashboard API fetch by replacing the placeholder brackets in `DATABASE_URL` with a valid mock Postgres connection string inside `.env.local`. This prevents the API route from crashing the React client during SSR and hydration.
- **Local Setup Guide**: Created `LOCAL_SETUP.md` with step-by-step instructions for preparing the local environment.
- **Environment Standardization**: Cleaned up `.env.example` to remove any hardcoded API keys, secrets, or duplicates. Validated all environment variables and standardized their placeholder values.
- **Feature Verification**: Conducted partial verification of existing features. Authenticated routes and empty states behave exactly as in Replit. Documented missing services (PostgreSQL) and explicitly marked all AI features as "Blocked — OpenAI API key required." in `FEATURE_VERIFICATION.md`.
- **AI Architecture Audit**: Completed an end-to-end analysis of AI functionality (`AI_ARCHITECTURE_AUDIT.md`) and proposed a migration plan for AI providers (`AI_PROVIDER_MIGRATION_PLAN.md`).
- **AI Provider Foundation (Milestone 4A)**: Implemented a robust Strategy Pattern via an `AIProvider` interface, Provider Registry, and Config layer inside `src/lib/ai/` to easily support future AI models (Gemini, OpenRouter, etc.). Existing OpenAI usage continues to function perfectly with no modifications to business logic.
- **Build Fixes**: Fixed a pre-existing path resolution error by migrating `lib/supabase.ts` to `src/lib/supabase.ts` and installing the missing `@supabase/supabase-js` package.
- **Gemini Provider Implementation (Milestone 4B)**: Implemented the `GeminiProvider` utilizing `@google/generative-ai`. Introduced robust error normalization, timeout mechanisms (`AbortSignal`), and exponential backoff retry wrappers across the entire AI Provider Foundation. Gemini is fully functional and ready to be used while preserving OpenAI as the default.
- **AI Structured Outputs**: Transitioned all AI prompts to use strict JSON structured output (`response_format: { type: "json_object" }` for OpenAI and `responseMimeType: "application/json"` for Gemini). Created strongly-typed schemas (`TitleAnalysisJSON` and `ScriptAnalysisJSON`).
- **Script Analysis Report**: Modularized the Script Analysis report into multiple sections (Executive Summary, Hook Analysis, Tone Analysis, Storytelling Analysis, Audience Analysis, CTA Analysis, Reusable Blueprint) each with individual AI confidence scores.
- **Script Generation Modes**: Added target length modes to Script Generation: "Exact Word Count", "Approximate Word Count", "Match Competitor", "AI Optimized", and "Max Retention".
- **Enhanced Library Metadata**: Updated the Title Formats database schema and API to save metadata including the original title, generated title, psychology, formula, hook type, and emotional trigger.
- **Milestone 3 (Local Parity & Persistence)**: Completed. Implemented a robust local JSON database fallback (`.local-db.json`) allowing the Library and History pages to persist data smoothly without needing a Postgres instance.
- **Milestone 4 (AI Provider Abstraction)**: Completed. The system securely routes generation tasks between OpenAI, Gemini, and OpenRouter architectures seamlessly.
- **Milestone 5B (AI Settings Backend)**: Implemented Zod-validated APIs (`/api/settings/ai` and `/api/settings/ai/test`) for dynamic configuration. Fallback mechanism implemented for testing multiple provider configurations efficiently via local `.ai-settings.json`.
